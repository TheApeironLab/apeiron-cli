    部署选项

    全新安装
    安装来源

    选择包含宸途部署程序和应用资源的完整离线包目录。也可以粘贴 CLI 主机上的路径。

    选择应用后检查实际安装资源，下载与校验通过后才会安装。

    集群类型

    应用通过 HTTPS 访问，HTTP 自动跳转。端口被占用时可修改；同一集群重试需沿用原端口。

    普通多机：1 个控制节点，其余为工作节点。高可用：至少 3 个、且为奇数个控制节点。

    节点连接

    检测系统、硬件、磁盘和 sudo 权限；不会安装软件。首次连接需先通过 ssh 确认主机指纹。

    访问方式

    平台入口

    公网入口目前支持在线单机 K3s。Caddy 管理 HTTPS 证书；内网主机主动连接已有 ECS，不需要访问者安装客户端。

    在 ECS 上运行下面的命令，将域名和 IP 换成你的值。入口需已安装 Caddy 2.10+。配对码 10 分钟有效，只授权一个设备，请勿分享。

    sudo apeiron platform entry pair --domain <slug>.apeironlab.cn --public-ip <ECS 公网 IP>

    撤销会立即关闭此入口的公网访问并使设备凭据失效，集群数据保留。恢复访问需要在 ECS 生成新的配对码。

    高级：手动 SSH 配置

    仅用于管理已有的手动连接。选择已配对入口后，这些字段不参与部署。

    仅监听 ECS 的 127.0.0.1；每个部署使用独立端口。

    公网入口需已安装 Caddy，开放 TCP 80 / 443。SSH 首次连接需确认主机指纹。公网 IP 不等于入口可达，部署前会检查 DNS，部署后检查 HTTPS。

    使用小写字母、数字和连字符，最多 63 个字符。

    内网使用无需购买域名。部署完成后，再引导你配置访问。

      浏览器在另一台电脑上时，请在那台电脑上配置。使用代理时，请将平台域名设为直连。
      

      手动配置 / 其他电脑
      下载 CA 证书下载 hosts 配置
      

      配置解析
      hosts 文件请合并条目，不要覆盖原文件：macOS / Linux 位于 /etc/hosts，Windows 位于 C:\Windows\System32\drivers\etc\hosts。
      

      信任 CA 证书

      macOS：打开下载的 chentu-ca.crt，添加到“系统”钥匙串；打开该证书，将“信任 → 使用此证书时”设为“始终信任”。需要管理员授权。
      Windows：将 chentu-ca.crt 导入“受信任的根证书颁发机构”。企业设备可由管理员统一分发。
      Ubuntu：将 chentu-ca.crt 复制到 /usr/local/share/ca-certificates/，然后执行 sudo update-ca-certificates。
      导入前核对下面的 SHA-256 指纹；个别浏览器使用独立证书库，需在浏览器中导入。分发的是公开 CA 证书，不包含私钥。
